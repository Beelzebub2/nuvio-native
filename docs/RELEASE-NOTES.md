Nuvio Native 1.0.10 fixes lingering episode synopsis popups and improves Watch Later and MyAnimeList action buttons.

- Episode synopses now close when the pointer leaves a card, including when moving to Home or outside the window. They stay visible while hovering to read, and moving between cards shows only the current synopsis.
- Watch Later cards now have prominent Play and Resume buttons, clear removal actions, and consistent icons and spacing.
- MyAnimeList status, rating, entry selection, and episode save/remove controls now use matching rounded buttons, dropdown indicators, hover feedback, visible keyboard focus, and accessible labels.
- Action groups wrap on narrower windows, with space reserved for dropdown arrows when labels need to shorten.

The Windows release is built and tested automatically when this version's Git tag is pushed. Windows installers retain SHA-256 checksums and private release distribution; they are not Authenticode-signed.
